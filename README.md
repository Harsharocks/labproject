# Product Engineering Lab

Small, independently implemented engineering case studies inspired by **publicly documented** product-company APIs and business workflows.

Each project is self-contained, uses synthetic examples, and includes an explanation of the problem, architecture, installation, execution, tests, and limitations. These are **educational demonstrations**, not official integrations or claims about companies' internal incidents.

## Projects

| Project | Inspired by | Focus | Tech |
| --- | --- | --- | --- |
| [Restaurant Order Reliability](restaurant-order-reliability/README.md) | Toast's publicly documented order-update webhooks | Event-id deduplication, stale-event protection, ordering conflicts | Java 21, standard library |

## Development approach

Prefer small, tested, incremental improvements over superficial activity. Next increments are tracked in each project's README.
